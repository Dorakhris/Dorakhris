## Featured Projects

### Splunk-Based Threat Analysis of OpenSSH Logs
<a href="https://github.com/Dorakhris/Splunk-Log-Analysis">
  <img align="right" width="200" src="https://user-images.githubusercontent.com/10972851/158226921-1c5c793c-2e67-4f4c-8118-a6d19a27e693.png" alt="Splunk Logo">
</a>
Conducted a full-cycle SOC investigation on live OpenSSH logs using **Splunk Cloud**. This project involved:
- **Ingesting and parsing** semi-structured log data.
- **Hunting for threats** using advanced SPL queries to uncover a targeted **brute-force attack**, **user enumeration**, and high-risk **Indicators of Compromise (IOCs)**.
- **Operationalizing intelligence** by building real-time monitoring dashboards and automated alerts for proactive defense.

**This project demonstrates my end-to-end capability to transform raw data into a clear, automated security monitoring solution.**

- **<a href="https://github.com/Dorakhris/Malware-Analysis/blob/main/README.md">Static & Dynamic Malware Analysis of .NET Executable</a>**
  - Performed a comprehensive analysis of a suspicious .NET executable, identifying "Confuser" obfuscation and uncovering its entire lifecycle: self-replication, registry-based persistence, and C2 communication attempts. Documented all IOCs and mitigation steps.

- **<a href="https://github.com/Dorakhris/Threat-Intelligence-Analysis-of-Ransomeware/blob/main/README.md">Threat Intelligence Analysis of DarkSide Ransomware</a>**
  - Identified DarkSide ransomware using VirusTotal, created a custom YARA rule for future detection, and mapped its observed TTPs directly to the MITRE ATT&CK framework, aligning with NIST 800-53 controls.

- **<a href="https://github.com/Dorakhris/Vulnerability-Assessment-lab/blob/main">Vulnerability Assessment & Automation Lab</a>**
  - Executed vulnerability scans with Nessus, developed Ansible playbooks to automatically patch identified weaknesses on a Linux/Nginx server, and configured automated reporting via SMTP.

- **<a href="https://github.com/Dorakhris/Forensics-Analysis-The-Stolen-Szechuan-Sauce/blob/main/README.md">Digital Forensics Case: The Stolen Szechuan Sauce</a>**
  - Analyzed a disk image with Autopsy to uncover evidence of data exfiltration and unauthorized access, mapping attacker actions to the MITRE ATT&CK framework.

- **<a href="https://github.com/Dorakhris/Phishing-Email-Analysis/edit/main/README.md">Phishing Email Investigation</a>**
  - Deconstructed a phishing email, analyzed its headers, and conducted OSINT to trace the origin of malicious IPs, providing a full report on the threat.

- **<a href="https://github.com/Dorakhris/Security-audit/blob/main/README.md">Linux Server Hardening Audit</a>**
  - Conducted a security audit of a Linux server, implementing and documenting security controls to harden the system against common attack vectors.

- **<a href="https://github.com/Dorakhris/Incident-Journal/blob/main/README.md">Incident Response Journal</a>**
  - Simulated and documented the response process for several attack scenarios, demonstrating a clear understanding of incident handling procedures.
