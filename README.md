### AI Lure Tracker

[View Project](https://github.com/Dorakhris/ai-lure-tracker)

A Python-based threat intelligence project designed to identify suspicious domains and software packages impersonating popular AI brands, including ChatGPT, Claude, Gemini and Copilot.

The project brings together threat feed collection, brand and package matching, indicator enrichment, heuristic scoring and structured threat data exports. Its documented workflow includes STIX 2.1 bundles, JSON and CSV feeds, automated reporting, MITRE ATT&CK mapping and optional integrations with MISP and OpenCTI.

I developed this project to explore how automated intelligence collection and analysis can help identify digital exposure, AI-brand abuse and potential software supply-chain threats.

**Skills:** Python · OSINT · Digital Risk Intelligence · Threat Intelligence Automation · Software Supply-Chain Security · STIX 2.1 · MITRE ATT&CK
